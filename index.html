School Newsletter Automation

An application that turns selected email and linked newsletter content into event summaries and calendar reminders.

Google access is granted by the account holder. Email access is read-only. Calendar access is limited to calendars created by the application. Uncertain event details require review.

This site provides application information only. It contains no email content, event data or account credentials and offers no public registration.
