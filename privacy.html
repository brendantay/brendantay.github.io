Privacy policy

School Newsletter Automation processes selected email messages and linked newsletter content to extract relevant events and reminders. Images may be read using local optical character recognition. No external generative-AI service is used.

Google permissions

Gmail access is read-only. The application does not send, delete or modify email. Separate Calendar access permits managing events only on calendars created by the application.

Use and storage

Data is processed locally or in a private GitHub Actions workflow. Credentials are stored locally and as encrypted workflow secrets. Private reports, calendar entries and an optional connected Android app may retain extracted information. Google, GitHub and Microsoft provide the services used for email, processing, calendars and linked newsletters.

Google user data is not sold, used for advertising, used for unrelated profiling or used to train general-purpose AI models. Use of Google API information follows the Google API Services User Data Policy, including Limited Use requirements.

Retention and control

Workflow report artifacts expire after seven days. Other reports, calendar entries, local review decisions and credentials remain until deleted through the relevant application or service. Revoking Google access stops future access but does not automatically erase existing reports or calendar entries. Service providers may retain backups under their own policies.

The account holder can disconnect the integration, stop scheduled processing, delete stored data and revoke authorization through Google Account connections.

This website

This documentation site contains no personal event data and uses no application analytics or tracking cookies. Its hosting provider may process ordinary request logs. Contact the support address shown on the Google authorization screen for privacy requests.
